
# summation formulas and properties


Given a sequence $\huge a_1, a_2, ..., a_n$ of numbers, $\huge n$ is non-negative integer 

the finite sum $\huge a_1  + a_2 + ... + a_n$  can be expressed as $\Huge \sum_{k=1}^{n} a_k$

if n == 0, the value of the summation is defined to be 0. 

> the order in which the terms are added does not matter.

# Arithmetic series


the summation 

$\Huge \sum_{k=1}^{n} k = 1 + 2 + ... + n$

is an _arithmetic series_ and has the value

$\Huge \sum_{k=1}^{n} k = \frac{n(n + 1)}{2}$


a _general arithmetic series_ includes a additive constant a >= 0 and a constant b > 0 in  each term, but has the same total asymptotically. 

$\Huge \sum_{k=1}^{n} (a + bk) = \theta(n^2)$


# Sums of squares and cubes

Squares
$\Huge \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n_1)}{6}$


Cubes

$\Huge \sum_{k=1}^{n} k^3 = \frac{n^2(n+1)^2}{4}$


# Geometric Series

real x != 1, the summation 

$\Huge \sum_{k=1}^{n} x^k = \frac{x^n+1 - 1}{x - 1}$


the infinite decreasing geometric series occurs when the summation is infinite and |x| < 1


$\Huge \sum_{k=1}^{\infty} x^k = \frac{1}{1 - x}$


if we assume that $0^0 = 1$, these formulas apply even when x = 0.
