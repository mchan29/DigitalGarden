The most efficient and effective to learn English extremely fast is to ==learn in context==.
- Input ( much easier to do on autopilot  )
	- Listening
	- Reading
- output ( requires deliberate practice )
	- Speaking
	- Writing

Grammar
- Skippable, It is like learning a different language. 
- Usability is low, Unless you trying to correct mistakes in English. 

Vocabulary 
- Picking up in context is fastest way to learn. 
	- Using in context is much more important than knowing many words.
- Learn by theme is another way to learn faster. 

Accent 
- Metric usually does not matter.
- Limitation : biological window.
- Extremely  easier to learn at the age of 3-7.
- Learning after above the age 17  is usually not possible. 
	- humans lose the ability to hear sounds.
