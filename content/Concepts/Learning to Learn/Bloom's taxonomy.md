

Source : 
- [Blooms Taxonomy - Best.pdf](https://www.utica.edu/academic/Assessment/new/Blooms%20Taxonomy%20-%20Best.pdf)



| Cognitive Level | Description | Core Action Verbs |
| :--- | :--- | :--- |
| **1. Remember** | Recalling basic facts, terms, and data from long-term memory. | Define, list, state, repeat, memorise, duplicate. |
| **2. Understand** | Explaining ideas, concepts, or summarizing information. | Classify, describe, discuss, explain, translate. |
| **3. Apply** | Using information or skills in completely new situations. | Execute, implement, solve, use, demonstrate. |
| **4. Analyze** | Breaking down information to explore structural relationships. | Differentiate, organize, compare, contrast, examine. |
| **5. Evaluate** | Justifying a decision, critique, or stand using strict criteria. | Appraise, argue, defend, judge, critique, weigh. |
| **6. Create** | Producing entirely original work or reorganizing parts into a new structure. | Design, assemble, construct, develop, formulate. |
